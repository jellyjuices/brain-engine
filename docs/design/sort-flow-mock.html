Proposal: always show where it went

One rule for every add: the owner sees a home before they save, the toast names it after, and anything the sort is unsure of waits on To-dos with its best guess, one tap to confirm. Mock only. Nothing is built.

What happens today

AddTodayWhy it frustrates
Quick to-doToast says only "Saved". The text becomes a capture in the inbox. The pull job files it to General if it has no subject. The sorter (#5) is not built.No home shown while typing, none after. It vanishes into General.
Person, place, thingOne name sheet, then "Added". The note is empty.No steps to say how they fit, so the note never grows.
.txt fileBecomes one Note tagged reference, linked to nothing. Toast "File added". No intake, no split.No name of where it went, no way to say what it is for.
