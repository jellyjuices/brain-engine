# Intent: Settings

**Intent:** a quiet place that shows which parts of the brain work right now, so the owner knows what to expect when something is offline.

## Problem

- Upkeep should not take space in the main screens.
- When something is offline, the owner cannot tell what still works.
- They need to see that their changes reached the home server.

## Outcomes

1. The owner sees whether the home server is reachable from where they are.
2. They see anything that has not synced yet.
3. They see how much storage the brain uses.
4. They see each sort step as on, off or not set up: rules, word matching, meaning matching, AI.
5. They can set the fingerprint lock.
6. They can see the app version and check for an update.

## User

The owner, when something seems off or out of date, or about once a month.

## Constraints

- Settings shows statuses. It has no toggles for how the brain works.
- Not in the tab bar.
- No theme or sorting settings. They are fixed in code.
- No settings for things that should just work.

## Open questions

1. Where Settings opens from on a small screen, in a large window, and in the menu bar popover.
